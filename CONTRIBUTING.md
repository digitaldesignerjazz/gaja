# Contributing to GAJA

Welcome, fellow innovator, squire, noble collaborator, or autonomous agent!

**GAJA** (Generative Agent Joined Architecture) is Sven Normen Esslinger's flagship initiative. It unites self-improving AI agent swarms, resilient mesh networking, blockchain-secured coordination, and rapid prototyping — all grounded in family tradition (Esslinger & Co.), privacy-first principles, and immersive creative exploration.

We build with excellence, curiosity, and a touch of noble flair.

## How to Contribute

### Reporting Issues
- Use GitHub Issues for bugs, feature ideas, architecture discussions, or epic visions (e.g., new swarm behaviors, Yggdrasil optimizations, QNET integrations).
- Label clearly: `bug`, `enhancement`, `mesh`, `agents`, `blockchain`, `prototype`, `documentation`.

### Pull Requests
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-amazing-idea`)
3. Write clean, documented code + tests where applicable
4. Update relevant docs in `docs/`
5. Open a Pull Request referencing the issue
6. Be responsive to review feedback

### Discussions & Roleplay
This project embraces immersive and creative contributions. Whether you're contributing Rust code for Grok Launcher-style agents, Python swarm orchestration, LaTeX whitepapers, or narrative scenarios involving agent swarms and noble titles — you're welcome. Feel free to roleplay as "Sir", "Squire", or your favorite agent persona in discussions.

## Development Setup
See the main [README.md](README.md) for installation and running instructions.

## Code Style & Standards
- **Rust**: idiomatic + egui patterns (inspired by Grok Launcher)
- **Python**: PEP8, type hints, clear agent interfaces
- **Documentation**: Update `docs/` and README when changing architecture
- **Commits**: Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`)

## Security & Privacy
- Never commit secrets, private keys, `.env` files, or wallet data (enforced by `.gitignore`)
- For sensitive R&D, consider private forks or branches initially
